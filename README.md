A ray tracer implementation in rust following the book [_Ray Tracing in One Weekend_](https://raytracing.github.io/books/RayTracingInOneWeekend.html)

How to run:

cargo run >> image.ppm 

where image.ppm is the name of the file with resulting image in PPM format
